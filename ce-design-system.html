Reference

Data Attributes Quick Reference

JS reads these data-* attributes to wire up interactivity — no extra configuration needed.

Attribute Element / Purpose
[data-ce-section]Activity section — tracked by the course controller
[data-ce-id]Unique section ID (e.g. "reading", "speaking")
[data-ce-name]Human-readable section name for ToC & dock
[data-ce-total]Number of completable steps in a section
[data-ce-module]Marks a section with internal page routing
[data-ce-sub]Sub-step within a section (story part, module page)
[data-ce-page]Named page within a module (e.g. "spk-1")
[data-ce-goto]On a topic/level button — target page ID
[data-ce-flash]Flash card container
[data-ce-flash-key]Unique key for progress tracking a flash card
[data-ce-quiz="single"]Standard MCQ with single correct answer
[data-correct="true/false"]On .ce-opt buttons — marks the correct answer
[data-explain]Explanation shown after answering an MCQ
[data-ce-timer] / [data-ce-seconds]Countdown timer for the timed quiz
[data-ce-audio] / [data-src]Audio player + URL to the mp3 file
[data-ce-winspeak]WinSpeak task container
[data-winspeak-id]Unique WinSpeak task ID (e.g. "u1-introduce")
[data-winspeak-mode]conversation | presentation | roleplay
[data-winspeak-rubric]Comma-separated scoring criteria
[data-ce-scan]Scan-for-facts game container
[data-ce-dnd]Drag-and-drop sentence builder
[data-ce-pos]Parts-of-speech tagger game
[data-ce-memory]Memory match card game
[data-ce-spin]Spin-and-define vocabulary game
[data-ce-sort]Synonym / antonym sort game
[data-ce-qf]Question factory game
[data-ce-fix]Fix-it editor game
[data-ce-writeblock]Writing prompt block with self-check
